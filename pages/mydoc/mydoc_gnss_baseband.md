GNSS remains an application direction for the programmable Venus architecture. This page does not publish a complete 1.0 demonstration or a qualified end-to-end result.

## Current public scope

The former late-2025 release forecast was an early plan. A delivery date is no longer claimed here. The published [Venus1 regression](venus1_validation.html) covers NR/LTE DAGs and does not include a GNSS qualification matrix.

## Explore an implementation

The [1.0 development workflow](mydoc_programming_model.html) can be used to prototype tasks for satellite navigation. A reproducible application contribution should supply the source, input data or input-generation procedure, configuration, expected outputs and measured behavior.

Start with the [installation example](venus1_get_started.html), then define the application contract with the team. [Contact ACE Lab](mailto:shenyihao@shu.edu.cn) about contributing a documented implementation.

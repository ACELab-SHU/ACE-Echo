Venusian 研究通过高层编程与基于 FPGA 的 RISC-V 加速器协同设计开展无线基带验证，将软件开发和硬件评估纳入同一研究流程，连接灵活的算法开发与硬件实验平台。

## 论文信息

**Venusian: Rapid Wireless Baseband Validation via High-Level Programming and FPGA-Based RISC-V Accelerator Co-Design**

Limin Jiang, Yi Shi, Yihao Shen, Yintao Liu, Shan Cao, Zhiyuan Jiang, Sheng Zhou

IEEE Transactions on Very Large Scale Integration (VLSI) Systems, 34(6), 2010-2014

这项成果展示了 Venus 相关研究的进展。平台支持的应用和验证结果见 [ACE-Echo 1.0 验证范围](zh_venus1_validation.html)。

## 项目概况
{: #project-overview }

- **项目名称**：Echo
- **所属单位**：上海大学通信与信息工程学院
- **项目时间**：2022 年 10 月至今
- **指导教师**：**Prof. Zhiyuan Jiang** 与 **Prof. Shan Cao**
- **目标**：为 AI 融合通信系统构建可扩展、高效率的 RISC-V 架构与仿真平台。

## 开发团队
{: #developer-team-overview }

开源项目汇聚了围绕 **Echo**、**Venus** 和 **AURA** 三个子项目开展工作的学生与研究者。以下名单保留自原始项目记录，用于致谢贡献，不代表完整的当前人员名册。

### Echo：应用与开发平台
{: #echo-applications-and-the-development-platform }

**负责人**：Yihao Shen

**贡献者**：Yi Shi、Limin Jiang、Qingyu Deng、Siyi Xu、Feng Yuan、Xiaoxiao Chen、Qianli Wang、Fangfang Ye、Si Wang

**工作方向**：

- 面向通信系统研究的开源平台
- 模块化通信协议栈实现，例如 5G/LTE 小区搜索
- 可复用通信算子库的设计与优化
- Venus 仿真与应用验证工作流

### Venus：领域专用 RISC-V 架构
{: #venus-domain-specific-risc-v-architecture }

**负责人**：Limin Jiang、Yi Shi

**贡献者**：Yintao Liu、Bo Ruan、Haiqin Hu、Qingyu Deng、Siyi Xu、Feng Yuan

### AURA：架构与编程基础
{: #aura-architecture-and-programming-foundation }

**贡献者**：Echo 与 Venus 项目的共同团队成员

**工作方向**：

- 领域专用编译器前端与后端
- 调度算法与运行时系统
- 支持跨平台 AI 融合、通信密集型应用的工具链

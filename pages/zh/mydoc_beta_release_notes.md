本页是 2025 年 6 月记录的 Echo v0.1 历史发布说明。使用基于 Gem5 的平台，请查看 [ACE-Echo 1.0 指南](zh_venus1_get_started.html)。

## 早期版本引入的内容
{: #what-the-early-release-introduced }

最初的版本整合了任务开发、面向通信的库、面向硬件的软件模型，以及早期 5G 小区搜索实验，形成了 ACE-Echo 后续演进的开发工作流。

原始功能描述对应当时的源码与示例，不是当前 1.0 支持矩阵，也不代表全面通过 3GPP 资格验证。[原始发布说明](https://github.com/ACELab-SHU/ACE-Echo/blob/8770c29996116dfd2bb791fdd5132a0949c294b3/pages/mydoc/mydoc_beta_release_notes.md)可在源码历史中查阅。

## 当前变化
{: #what-changed }

ACE-Echo 1.0 使用 Gem5 进行 Venus 应用开发和近似周期级性能评估。初版 Agent 框架在开发者指导下辅助工作。

旧 v0.5 和 v1.0 beta 预测已被替代。请通过[当前路线图](zh_roadmap.html)了解 1.0 范围与 2.0 意图驱动开发方向。
